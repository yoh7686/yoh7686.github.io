# 個人サイトの更新

Python 3.10以降のみで生成できる静的サイトです。既存のゲーム配布フォルダは変更しません。

## 公開用の原稿

`content/` の Markdown がサイトの公開用原稿です。各 `## 見出し` が1項目、その下の `- key: value` が属性です。既存の `id` は変更しないでください。各ページ・Newsからのリンクに使います。

- `profile.md`: 名前・肩書き・略歴
- `activities.md`: 講演・講義・メンター・審査員など
- `research.md`: 論文・書籍・研究発表・受賞
- `works.md`: 会社・個人・研究の作品
- `videos.md`: YouTube動画
- `media.md`: 記事・インタビュー・活動紹介（告知だけの記事は除外）

日付は `YYYY-MM-DD` / `YYYY-MM` / `YYYY` の精度を保ちます。日付不明は省略します。Newsは活動・動画・メディアの公開用原稿から自動生成します。実施済みの公開項目だけを追加してください。

## 更新手順

1. 公開用 Markdown を編集する。
2. リポジトリのルートで `python3 portfolio/build.py` を実行する。
3. `python3 portfolio/check.py` で内部リンクなどを検査する。
4. Markdown と生成された HTML を一緒にコミットして `master` に push する。
5. 既存の GitHub Pages のブランチ公開により反映される。

ローカル表示: リポジトリのルートで `python3 -m http.server 8765` を実行し、`http://localhost:8765` を開く。

Driveの管理原簿は非公開メモを含むため、このリポジトリにコピーしないでください。公開版では出典メール、依頼者名、内部メモ、辞退、未確認の予定を扱いません。Driveは調査・照合用、ここのMarkdownはサイト公開用です。管理原簿を編集しただけではサイトには反映されません。

初回移行では、活動のうち公開記録と実施状況を確認できた75件を採用しました。管理原簿の全605件をそのまま公開していません。本人提供の動画31件、メディア71件、業績原簿の研究等93件・作品23件と既存の公開ゲーム1件を収録しています。

作品の代表カードは `build.py` の `FEATURES` に定義しています。画像差し替え・代表作品の変更はここを編集します。会社での制作・個人制作・研究作品の3区分を維持してください。YouTubeサムネイルは外部画像を読み込み、動画はリンク先で再生します。記事の本文や画像は複製していません。
