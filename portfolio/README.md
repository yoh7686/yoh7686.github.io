# 個人サイトの更新

Python 3.10以降の標準ライブラリで公開用Markdownから静的HTMLを生成します。既存のゲーム配布フォルダは操作しません。

## 原稿

`content/` の各 `## 見出し` が1項目、その下の `- key: value` が属性です。既存の `id` はリンクのため変更しないでください。

- `profile.md`: 正式な所属・役職、略歴、写真
- `activities.md`: 講演・講義・メンター・審査など。予定は掲載しない
- `research.md`: 書籍・論文・研究発表・受賞など
- `works.md`: 商業作品・個人制作・研究作品
- `videos.md`: YouTube動画。`published_at` に元の公開日時、`date` に日本時間の公開日
- `media.md`: メディア掲載。告知のみの記事は除外
- `video-dates.md`: 動画公開日の確認結果

`featured: true` を付けた作品・動画がトップの代表作品に表示されます。作品の `image` にサムネイルURL、`url` に公開先、`description` に担当・説明、`credit` に画像の出典を指定します。作品の存在をリポジトリから自動収集しません。掲載する作品は本人が指定したものだけを原稿に追加してください。

各分類の一覧は日付の新しい順です。活動は `/activities/YYYY.html` に年ごとに生成され、`/activities.html` が年別の入口です。原稿605件のうち予定6件を除く599件を収録しています。実施確認中・同一性未確認の記録には注記し、実施回数として合計しません。これらはNewsの「実施しました」には出しません。

## 更新手順

1. 公開用Markdownを編集する。
2. ルートで `python3 portfolio/build.py` を実行する。
3. `python3 portfolio/check.py` でリンクや掲載対象を検査する。件数の検査は原稿追加時に更新する。
4. 原稿と生成されたHTMLを一緒に `master` にコミット・pushする。
5. GitHub Pagesの公開完了を確認する。

ローカル表示は `python3 -m http.server 8765` と `http://localhost:8765` で確認できます。

Driveの管理原簿は内部メモを含むのでリポジトリへコピーしないでください。公開用原稿にはイベント名・演題・日付・分類などの表示項目だけを転記します。予定・辞退・非公開の照合記録は追加しません。Driveは調査・照合用、ここのMarkdownはサイト表示用です。
