# 個人サイトの更新

Python 3.10以降の標準ライブラリで公開用Markdownから静的HTMLを生成します。既存のゲーム配布フォルダは操作しません。

## 原稿

`content/` の各 `## 見出し` が1項目、その下の `- key: value` が属性です。既存の `id` はリンクのため変更しないでください。

- `profile.md`: 正式な所属・役職、略歴、写真
- `activities.md`: 講演・講義・メンター・審査など。予定は掲載しない
- `research.md`: 書籍・論文・研究発表・受賞など
- `works.md`: 商業作品・個人制作・研究作品
- `videos.md`: YouTube動画。`published_at` に元の公開日時、`date` に日本時間の公開日
- `media.md`: メディア掲載。告知のみの記事は除外
- `video-dates.md`: 動画公開日の確認結果

`featured: true` を付けた作品・動画が公開時期にかかわらずトップに固定表示されます。作品の `image` にサムネイルURL、`url` に公開先、`description` に担当・説明、`credit` に画像の出典を指定します。`video_url` に紹介動画を指定すると、作品・資料のリンクと分けて表示します。作品の存在をリポジトリから自動収集しません。作品を新しく掲載する前に、対象作品と掲載内容を簗瀬洋平本人に提示し、明示的な了承を得てください。了承を得るまでは、作品原稿への追加、公開ブランチへの配布ファイルの追加、GitHub Pagesへの公開を行わないでください。直接URLからアクセスできる配布ファイルも公開に含みます。

各分類の一覧は日付の新しい順です。活動は `/activities/YYYY.html` に年ごとに生成され、`/activities.html` が年別の入口です。原稿605件のうち予定6件、掲載対象外の定期講義1件、未実施の活動1件を除く597件を収録しています。同一活動の可能性がある記録には注記し、実施回数として合計しません。`omit_news: true` の記録と同一性未確認の記録はNewsには出しません。

## 更新手順

1. 公開用Markdownを編集する。
2. ルートで `python3 portfolio/build.py` を実行する。
3. `python3 portfolio/check.py` でリンクや掲載対象を検査する。件数の検査は原稿追加時に更新する。
4. 原稿と生成されたHTMLを一緒に `master` にコミット・pushする。
5. GitHub Pagesの公開完了を確認する。

ローカル表示は `python3 -m http.server 8765` と `http://localhost:8765` で確認できます。

Driveの管理原簿は内部メモを含むのでリポジトリへコピーしないでください。公開用原稿にはイベント名・演題・日付・分類などの表示項目だけを転記します。予定・辞退・非公開の照合記録は追加しません。Driveは調査・照合用、ここのMarkdownはサイト表示用です。

プロフィール写真は電気通信大学CERECの本人紹介写真を使用。画像の出典はprofile.mdに記録しています。お問い合わせ窓口は未指定のため準備中です。

研究・著作は `url` を必須とし、`source_label` で「論文（DOI）」「公式プログラム」など掲載先の種類を示せます。書籍は `book_title`、`image`（書影）、`image_credit` を設定できます。出版社の商品ページが確認できない場合は書誌情報を主リンクとし、`publisher_url` に出版社サイトを別途指定します。
